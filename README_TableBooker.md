# TableBooker

Учебный backend-проект на **NestJS + PostgreSQL**, цель которого — показать не только CRUD, но и реальную бизнес-логику бронирования столиков.

## Зачем этот проект

Проект нужен как портфолио и как практическая база для перехода в backend-разработку на NestJS. Основной акцент:

- проектирование сущностей и связей в PostgreSQL;
- работа с SQL без прятания за ORM;
- логика бронирования и проверка конфликтов по времени;
- постепенное развитие архитектуры от модульного монолита к микросервисам.

## Идея проекта

Есть 2 ресторана. Пользователь может:

- выбрать ресторан;
- увидеть столики и их вместимость;
- выбрать дату и время;
- создать бронь на слот по умолчанию **2 часа**;
- подтвердить или отменить бронь.

Планируется поддержка двух типов столов:

- **REGULAR** — столик бронируется целиком;
- **SHARED** — общий стол, на который могут бронироваться отдельные места.

## Основные сущности

- `restaurants`
- `restaurant_tables`
- `users`
- `bookings`
- опционально `booking_seats` для более точной логики общих столов

## Статусы брони

- `HOLD`
- `CONFIRMED`
- `CANCELLED`
- `EXPIRED`

## Стек

- **NestJS**
- **PostgreSQL**
- **SQL migrations**
- **Docker Compose**
- позже:
  - **Redis**
  - **RabbitMQ**
  - **gRPC**
  - **Next.js frontend**

## Почему без Prisma на старте

Prisma удобна и понятна, но в этом проекте цель — лучше почувствовать:

- таблицы;
- связи;
- индексы;
- SQL-запросы;
- транзакции;
- ограничения базы данных.

## Архитектурный принцип

Старт — **модульный монолит**, а не мгновенный зоопарк микросервисов.  
Когда ядро бронирования станет понятным и устойчивым, отдельные части можно вынести в:

- notifications-service
- booking-worker
- внешние integration modules

## Что проект должен показать работодателю

- умение работать с NestJS не только на уровне контроллеров;
- понимание SQL и схемы БД;
- проектирование бизнес-логики бронирования;
- умение постепенно усложнять архитектуру без хаоса.

## Локальный запуск

```bash
git clone <repo-url>
cd tablebooker
docker compose up -d
npm install
npm run start:dev
```
